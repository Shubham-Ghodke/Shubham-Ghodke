## Projects

### 🔮 [ClarifAI](https://github.com/Shubham-Ghodke/ClarifAI) — AI Customer Support
*   **Description**: A multilingual RAG (Retrieval-Augmented Generation) customer support chatbot that provides citation-backed answers grounded in uploaded documents.
*   **Tech Stack**: Python, FastAPI, React, Google Gemini, FAISS, BM25
*   **Details**: Developed a hybrid search pipeline combining dense vector embeddings (FAISS) with sparse keyword matching (BM25) to improve retrieval accuracy. Integrated the Gemini API to format structured citations and prevent hallucinations.
*   **Links**: [GitHub Repository](https://github.com/Shubham-Ghodke/ClarifAI) | [Live Demo](https://clarifai-rag.vercel.app)
